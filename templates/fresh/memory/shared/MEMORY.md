# Shared Memory — Index (every session reads this)

What all sessions need, whatever desk they sit at. Keep it small: this is paid
for by every session before it does any work.

## Rules

- Absolute dates, one topic per file, delete what is proven wrong.
- **Never secrets**, and never personal content in project memories.
- Anything durable goes in the repo memory, not the per-machine auto-memory —
  that is what makes this system portable.
